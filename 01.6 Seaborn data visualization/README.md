
# Seaborn Data Visualization Guide

A collection of Jupyter notebooks covering essential Seaborn plots for data visualization in Python.

## 📁 Notebooks Overview

| Notebook | Topic | Plots Covered |
|----------|-------|---------------|
| `00 Seaborn_Plot_Types_Guide.pdf` | Complete reference guide | All plot types overview |
| `01 sea_born_visualization.ipynb` | Getting started | Basic Seaborn setup and usage |
| `02_Distribution_plots.ipynb` | Distribution plots | `histplot`, `kdeplot`, `ecdfplot` |
| `03_Categorical_plots.ipynb` | Categorical plots | `barplot`, `countplot`, `boxplot`, `violinplot`, `stripplot` |
| `04_corelation_with_heatmap.ipynb` | Correlation analysis | `heatmap` with correlation matrices |

## 🚀 Getting Started

1. Install dependencies:
```bash
pip install seaborn matplotlib pandas numpy
```

2. Open any notebook:
```bash
jupyter notebook <notebook_name>.ipynb
```

## 📊 What You'll Learn

- How to visualize data distributions
- How to compare categories
- How to find correlations between variables
- Best practices for choosing the right plot
