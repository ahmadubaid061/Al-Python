# 📊 Matplotlib Data Visualization

This folder contains Jupyter notebooks covering different matplotlib visualizations.

## 📁 Files

| File | Description |
|------|-------------|
| `01_undestanding_figure` | Understanding figure and axes basics |
| `02_Line_and_scatter_plot` | Line charts and scatter plots |
| `03_plots_inside_a_figure` | Adding multiple plots in one figure |
| `04_bar_charts` | Creating bar charts |
| `05_Histogram_and_density_plot` | Histograms and density plots |
| `06_subplots` | Multiple subplots in a grid |
| `07_error_bars` | Adding error bars to plots |

## 📦 Dataset

- `ecommerce_dataset.csv` - Sample e-commerce data used in the notebooks

## 🚀 Getting Started

Run the notebooks in order (01 → 07) for a progressive learning experience.
